# 🎮 Арканоид

Классический арканоид в браузере — один HTML-файл, без зависимостей и сборки.

**▶️ Играть: [valeria118.github.io/arkanoid](https://valeria118.github.io/arkanoid/)**

Работает на компьютере и телефоне. На телефоне выглядит как нативное приложение: поле на весь экран, управление пальцем, можно добавить на главный экран.

## 🕹 Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Платформа | Мышь или `←` `→` / `A` `D` | Вести пальцем по экрану |
| Запуск мяча | Пробел или клик | Тап |
| Пауза | Пробел | — |

Способ управления выбирается в меню. Плавная инерция движения — платформа разгоняется и тормозит мягко.

## 🎯 Что внутри

- **5 уровней** с уникальными узорами: стена, шахматка, пирамида, колонны, ромб-босс
- **Стальные блоки** — не разрушаются, только отбивают мяч
- **Движущиеся блоки** — прицеливаться сложнее и интереснее
- **Бонусы** (падают из особых блоков):
  - `W` — платформа шире
  - `3x` — три мяча одновременно
  - `S` — замедление мяча
  - `♥` — дополнительная жизнь
- **Растущая сложность**: скорость мяча и ширина платформы меняются от уровня к уровню
- **4 темы оформления**: светлая, тёмная, тёплая, мятная — переключаются на лету
- Звук, частицы-осколки, шлейф мяча, анимации переходов между уровнями
- Адаптация под любой экран — поле подстраивается по ширине и высоте

## 🛠 Технологии

- HTML5 Canvas + vanilla JavaScript
- WebAudio API (звук без файлов)
- Один файл `index.html`, никаких зависимостей

## 🚀 Как запустить локально

Просто откройте `index.html` в браузере. Или:

```bash
git clone https://github.com/valeria118/arkanoid.git
cd arkanoid
start index.html   # Windows
```
